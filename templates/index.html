輕量簡潔

Flask 擁有微框架（Micro-framework）的極致輕量特性，核心單純無負擔，適合快速建構各類 Web 專案。

🎨

Jinja2 模板

強大的模板引擎，讓前後端資料整合變得無比流暢，輕鬆呈現動態內容與精緻使用者介面。

🔗

RESTful API 支援

內建完備的 JSON 序列化工具與路由控制，可無縫兼顧單頁應用（SPA）與前後端分離架構。
